Authorization contexts

An authorization context is defined by a role, scope, and optional group.

Roles define which actions you can perform:

Read
May read annotations (including comments and versions) within the specified scope.
Edit
May directly create, read, update, and delete annotations and propose change sets to annotations with the specified scope.
Admin
Has full control over annotations within the specified scope, including accepting and rejecting change sets.

Scopes define which annotations you can access:

Self
Annotations you created.
Group
Annotations created by members of a specific group.
Global
All annotations in the system.

Authorizations with a group or self scope are also tied to a specific group. All annotations created using that authorization will be owned by that group.

Authorizations with a global scope are not tied to any group. The owning group must be specified when creating annotations with that authorization.
